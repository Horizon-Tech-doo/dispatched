# Design references

`m1b-mockup-a.dc.html` is the approved direction A mockup, saved from the private canvas https://claude.ai/artifact/85qsVo8NmMQagPRXus4MwX (artboard "A. Workbench", 1440x900, with a dark/light theme tweak).
Its palette lives in the `PAL` object of the script block.
It is a visual reference for M1b UI work and reviews, not product code: do not import or ship it.
The `.dc.html` source needs the canvas runtime and does not render on its own; `m1b-mockup-a-dark.png` and `m1b-mockup-a-light.png` are renders of it at 1440x900 (2x), for reviews.
