Dispatched 0.1.0 is the first public preview: a native desktop app and a scriptable CLI for Azure Service Bus on macOS, Windows and Linux. Free and open source.

## What's in it

- **Browse:** the namespace tree with message counts, a dashboard of every count, and peek views for messages, dead letters, the transfer dead-letter queue, scheduled and deferred messages and sessions. Peeking never locks, receives or settles a message.
- **Find:** filter by property, body text, regex or JSONPath; open any message as JSON, XML, text or hex; group dead letters by reason; export messages.
- **Operate:** send (composer, files, templates, schedules), receive and settle, resubmit with edits, move, delete, purge, cancel scheduled messages, settle deferred ones and edit session state. Long jobs can be cancelled, and their reports saved.
- **Manage:** create, edit, duplicate, rename and delete queues, topics and subscriptions; SQL and correlation rules; SAS policies (keys are copied to the clipboard, never shown); import and export XML entity files in the widely used ServiceBusExplorer format.
- **Listen:** watch new messages arrive, or receive and complete them, with messages and bytes per second.
- **Safe on production:** every change is counted and stated in one sentence before it runs. On a connection marked as production you type the name of every entity the change touches, and every change is written to a local activity log shared with the CLI.
- **Sign-in:** Microsoft Entra ID (multi-tenant, with namespace discovery) or a connection string, with secrets in the system keychain; AMQP over TCP or WebSockets, with proxy support.
- **CLI:** the `dispatched` command with the same operations and confirmations, and `--format json` for scripts.

## Downloads

| Platform | Desktop app | CLI |
|---|---|---|
| macOS 13.3 or later (Apple silicon and Intel) | `Dispatched_0.1.0_universal.dmg` (signed and notarized) | `dispatched-cli_0.1.0_macos-universal.zip` |
| Windows 10 and 11, x64 | `Dispatched_0.1.0_x64-setup.exe` or `.msi` | `dispatched-cli_0.1.0_windows-x64.zip` |
| Windows on ARM | `Dispatched_0.1.0_arm64-setup.exe` | `dispatched-cli_0.1.0_windows-arm64.zip` |
| Linux x64 | `.AppImage`, `.deb`, `.rpm` (amd64 / x86_64) | `dispatched-cli_0.1.0_linux-x86_64.tar.gz` |
| Linux arm64 | `.AppImage`, `.deb`, `.rpm` (aarch64 / arm64) | `dispatched-cli_0.1.0_linux-aarch64.tar.gz` |

Each CLI archive has a `.sha256` checksum next to it. The desktop app checks for updates itself.

## Preview notes

- The Windows installers are not code-signed yet, so SmartScreen asks before the first run ("More info", then "Run anyway").
- Settings, connections and the activity log may change format before 1.0; a later preview may ask you to sign in again.
- Report problems at https://github.com/Horizon-Tech-doo/dispatched/issues or hello@horizon-tech.io. Never paste connection strings, keys or message contents into an issue.
